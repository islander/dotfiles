# My dotfiles v2.0

_powered by_ [stow](https://www.gnu.org/software/stow/)

## Usage
```
~$ git clone https://github.com/islander/dotfiles.git
~$ cd dotfiles
~/dotfiles$ stow -v mise/
LINK: .config/mise => ../dotfiles/mise/.config/mise
```
